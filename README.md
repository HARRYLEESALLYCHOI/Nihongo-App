# 일본어 단어 테스트 (3강~5강)

일본어 3강~5강 단어와 조사·부사·접속사 정리를 시험처럼 풀어 보는 앱이에요.
폰 홈 화면에 설치하면 일반 앱처럼 열리고, 한 번 열어 두면 인터넷 없이도 돼요.

## 기능

- **범위 고르기**: 3강 / 4강 / 5강 / 조사·부사·접속사를 원하는 대로 조합
- **한자 단어만** 따로 모아서 시험 (22개)
- **출제 방향**: 일본어 → 한국어, 한국어 → 일본어, 한자 읽기, 한자 쓰기, 빈칸 채우기(조사·부사 예문)
  - 여러 개 고르면 문제마다 섞여서 나와요
- **풀이 방식**: 5지선다(①~⑤) 또는 직접 쓰기
  - 5지선다에는 요음·촉음을 크게 쓰거나 장음을 뺀 함정 보기가 섞여 나와요
  - 직접 쓰기는 로마자로 쳐도 가나로 바꿔서 채점해요 (densha → でんしゃ)
- 시험 볼 때마다 문제 순서와 보기가 새로 섞여요
- **오답노트**: 틀린 단어가 자동으로 모이고, 맞히면 빠져요
- **단어장**: 검색, 뜻 가리기, 발음 듣기(🔊)

## GitHub에 올려서 앱으로 만들기

### 1. 저장소 만들기
1. GitHub에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name에 이름 입력 (예: `nihongo-tango`)
3. **Public** 선택 → **Create repository**

### 2. 파일 올리기
1. 만들어진 저장소 화면에서 **uploading an existing file** 링크 클릭
2. 압축을 푼 폴더 **안에 있는 것들**을 전부 끌어다 놓기
   - `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `icons` 폴더
   - 폴더째로 올리면 안 되고, `index.html`이 저장소 맨 위에 있어야 해요
3. 아래 **Commit changes** 클릭

### 3. GitHub Pages 켜기
1. 저장소 위쪽 **Settings** → 왼쪽 메뉴 **Pages**
2. Build and deployment의 Source를 **Deploy from a branch**로
3. Branch를 **main**, 폴더를 **/ (root)**로 고르고 **Save**
4. 1~2분 기다리면 `https://내아이디.github.io/저장소이름/` 주소가 생겨요

### 4. 폰에 설치하기
- **아이폰**: Safari로 주소 열기 → 아래 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**

### (선택) 안드로이드 APK로 만들기
[PWABuilder](https://www.pwabuilder.com)에 위 주소를 넣으면 안드로이드 앱 패키지로 만들 수 있어요.

## 단어 추가하기 (6강 이후)

`index.html`을 열어서 `const WORDS = [` 부분에 줄을 추가하면 돼요.

```js
{id:'6-01', l:'6', jp:'電話', r:'でんわ', kr:'전화'},      // 한자 단어는 r(읽기)도 적기
{id:'6-02', l:'6', jp:'ゆうびんきょく', kr:'우체국'},
```

새 강을 추가했으면 같은 파일에서 `const LESSONS =` 줄에도 `['6','6강']`을 넣어 주세요.

- `id`는 겹치면 안 되고, 한 번 정하면 바꾸지 않는 게 좋아요 (오답노트 기록에 쓰여요)
- 표기가 두 개면 `jp:'こっち / こちら'`처럼 ` / `로 구분
- 예문에 `【 】`로 감싼 부분이 있으면 빈칸 채우기 문제로 나와요

파일을 고친 다음에는 `sw.js` 맨 위의 `const VERSION = 'v1';`을 `'v2'`, `'v3'`… 로 올려 주세요.
그래야 이미 설치한 폰에도 바뀐 내용이 들어가요. (앱을 두 번쯤 껐다 켜면 반영돼요)

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 앱 전체 (화면, 단어 데이터, 채점) |
| `manifest.webmanifest` | 앱 이름, 아이콘, 색 (홈 화면 설치용) |
| `sw.js` | 오프라인에서도 열리게 해 주는 파일 |
| `icons/` | 앱 아이콘 |

오답노트와 설정은 각자 폰(브라우저)에 저장돼요. 다른 폰과는 공유되지 않아요.
